# 上海学校观察

上海新东方校区和学校参考位置地图，支持学校与校区的双向查找、直线距离、P级名录及本地匿名学生数据试用。

数据是历史研究快照，不是实时名册；位置与营业状态需进一步核实。直线距离不代表实际路线或学生来源。未定位学校不等于范围外。学校与校区资料随本仓库公开，请确认更新资料的发布授权。

学生 CSV 仅在当前浏览器页面内处理，刷新会丢失；不应导入姓名或联系方式，当前版本没有数据库或权限管理。默认底图为随网站发布的上海简化道路/水系/地名，不访问外部瓦片服务器；另有可选 OpenStreetMap 在线街图，失败后自动退回自带底图。来源、日期与 ODbL 许可见 `web/basemap/README.md`，Leaflet 许可证见 `web/vendor/LICENSE.txt`。

点击地图上的学校或学校卡片主区域，直接以该校址为中心查看所设半径内的新东方校区；右侧清单按距离排序。多校址学校可切换计算起点；半径支持 0.1 km 精度，普通和全屏模式均可调整。更换学校筛选或视图会退出反查，调整半径则保留学校。可点击校区查看参考地址，或选择“查看画像”阅读学校资料；“自选校区连线”仍独立使用。反查视图支持分享学校、校址、半径及导出附近校区 CSV。距离均为直线参考，不代表学生来源。

触摸板滚动缩放采用 0.25 级精度，地图加减按钮为 0.5 级；相较 Leaflet 默认配置降低了滚动灵敏度。真实设备的手势速度可能不同。

P0 的21所学校介绍见 `web/p0-introductions.js`，核验记录见 `sources/P0学校介绍核验_20261030.md`。页面展示介绍来源、来源发布日期、查阅日期和核验状态。20所学校有政府/学校原始正文支持，P015 的介绍仍待原始来源补核；P021 为2019年历史资料。P0 是项目收集优先级，不是官方评级。

## 检查

```sh
node tests/p0-introductions.cjs
node tests/local-map.cjs
python3 -m http.server 18823 --bind 127.0.0.1 --directory web
# 在另一个终端，使用已安装的 ego-browser：
ego-browser nodejs < tests/map-interactions.mjs
```

交互检查会创建并收尾独立浏览器空间，不操作用户已有页面。`ATLAS_TEST_URL` 可指定要检查的线上地址。

GitHub Pages 从 `main` 分支经 Actions 发布 `web/`。在本机修改原项目后，须将需要发布的文件同步到本目录的 `web/`，检查差异并提交、推送；等待 Actions 完成后再检查线上页面。请勿把私人学生数据、账号凭据或未获公开授权的资料加入仓库。
